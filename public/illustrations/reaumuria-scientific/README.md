# 红砂复制 · 科学插图资产

本目录保存“红砂复制”页面使用的透明 WebP 科学插图。图像由 GPT Image 2 的内置图像生成能力绘制，参考红砂实拍照片与 Flora of China 形态描述；生成时使用纯青色抠像底，再在本地转换为 Alpha 图像并以高质量 WebP 编码。所有成品图内均无文字、标签、比例尺、水印或伪文字。

| 文件 | 图槽用途 |
| --- | --- |
| `main-plant.webp` | 主株全貌、砾质盐渍土基部 |
| `season-spring.webp` | 春季新梢与肉质叶 |
| `season-summer.webp` | 夏季粉白色五瓣花 |
| `season-autumn.webp` | 秋季红褐色蒴果 |
| `season-winter.webp` | 冬季木质枝与枯萼残迹 |
| `trait-leaf.webp` | 肉质短圆柱状/鳞片状叶 |
| `trait-flower.webp` | 五瓣花与雄蕊近景 |
| `trait-glands.webp` | 小枝红色腺点近景 |
| `trait-calyx.webp` | 蒴果与宿存花萼 |
| `similar-cistanche-salsa.webp` | 盐生肉苁蓉对照 |
| `similar-haloxylon.webp` | 梭梭对照 |
| `humanities-fieldwork.webp` | 荒漠植被样方调查 |

“典型生境”图槽按任务要求保持空白，不使用生成插图。

## 形态与照片依据

- Flora of China: [Reaumuria soongarica](http://www.efloras.org/florataxon.aspx?flora_id=2&taxon_id=242343205)，用于株高、枝色、叶形、盐腺、花、蒴果和物候约束。
- iNaturalist: [Reaumuria songarica](https://www.inaturalist.org/taxa/928561-Reaumuria-songarica)，实拍参考图为 `photo 173798030`，用于叶簇、花果与枝条姿态。
- Plantarium: [Reaumuria songarica specimen image](https://www.plantarium.ru/lang/en/page/next/for/260261.html)，用于花枝与叶簇参考。
- Kew Plants of the World Online: [Reaumuria songarica](https://powo.science.kew.org/taxon/urn:lsid:ipni.org:names:828014-1)，用于名称与分类交叉核对。

主要生成约束：低矮多分枝小灌木；灰褐老枝、红色曲折小枝；灰蓝色肉质短圆柱状/鳞片状叶；白至淡粉、带红晕的五瓣小花；狭椭圆或纺锤形蒴果与宿存花萼。插图仍应在印刷前与标本或野外照片复核。
