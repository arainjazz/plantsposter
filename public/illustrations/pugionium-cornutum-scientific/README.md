# 沙芥（*Pugionium cornutum*）科学插图

本目录的 12 张 PNG 用于沙芥页面的主图、物候、识别特征、近似种对照和植物人文图槽。每张均为无文字的透明背景图；页面的“全球分布”与“典型生境”图槽未改动。

## 形态参考

- [Zhang *et al.*, 2021, *PNAS*](https://pmc.ncbi.nlm.nih.gov/articles/PMC8545485/)，图 1：沙芥与长角沙芥的真实植株、叶和果实照片；用于核对生成图的整体习性、叶形和两种果实轮廓。
- [Plants of the World Online](https://powo.science.kew.org/taxon/urn%3Alsid%3Aipni.org%3Anames%3A288314-1)：接受名与分类核对。

生成时使用洋红色抠图背景，并以本项目的透明边缘处理流程转换为 RGBA PNG。
